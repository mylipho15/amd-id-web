Installation Guide

Follow these steps to install R.ID Drivers on your system

1

Download DDU (Display Driver Uninstaller)

Download DDU from the official source. This tool will help you cleanly remove existing drivers before installing R.ID Drivers.

2

Disconnect Internet

Disconnect your internet connection to prevent Windows Update from automatically installing drivers.

3

Run DDU in Safe Mode

Boot into Safe Mode and run DDU to remove existing AMD drivers. Select "GPU" and "AMD" then click "Clean and restart".

4

Install R.ID Drivers

After restart, run the R.ID driver installer. Follow the installation wizard and select your preferred components.

5

Restart and Verify

After installation completes, restart your computer. Verify the driver installation in Device Manager or AMD Software.

Note: Only use DDU or AMD Cleanup if this is your first time installing R.ID drivers, or you have problems when doing dirty install a.k.a. update the drivers directly.
